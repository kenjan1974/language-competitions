# 字音字形奇幻牧場 (WordRanch PWA)

專為台灣國小學生準備「語文競賽（字音字形）」並銜接國中會考／高中學測國語文素養設計的單人離線優先 PWA 養成遊戲，針對 **iPad 觸控與 Apple Pencil 手寫** 深度最佳化。

## 🎮 V2 核心特色

### 1. 📚 3,457 題歷屆完整題庫 ＋ 教育部辭典與字首字根「不死背」學習系統
* **完整收錄 3,457 道考古題**（字音 1,710 題 ＋ 字形 1,747 題，涵蓋歷屆全國賽與校隊試題，自動去重並累計歷屆高頻出現次數）。
* **教育部《重編國語辭典修訂本》（萌典 Open Data）離線釋義注入**：內建 **99.7% 單字部首釋義**、**68%+ 詞義與經典典故出處**（如《論語》、《漢書》、《左傳》）與 **420 題一字多音語境對照**，完全離線可用。
* **三層式語境記憶設計**：
  * **字音關（疾風字音陣）**：限時四選一快問快答，答對即時顯示詞義膠囊；**答錯或超時時暫停自動跳題**，展開「🧩 字首字根拆解（形符＋聲符）＆ 一字多音對照卡」，看懂後再手動點擊進入下一題。
  * **字形關（首領字形破陣・雙軌手寫）**：題目卡直接提供「📖 詞語意思」、「🔤 單字本義」與「🧩 部首字根意符」提示，讓孩子理解字義後再動筆。
    * **標準筆順盲寫 (`Hanzi Writer`)**：米字格盲寫測驗，連錯 2 筆閃爍提示下一筆，支援「偷看一秒」與光系夥伴免費聖光偷看。
    * **Apple Pencil 自由手寫翻牌 (`HTML5 Canvas`)**：生僻字或離線自動降級（亦可隨時手動切換），支援感壓手寫、復原筆畫與翻牌核對標準楷體。
  * **結算回顧與個人錯題本**：每局結束提供「📜 本局字詞知識回顧清單」；錯題本支援展開「🔗 同字家族／一字多音對照表」、單題直接練寫，以及「👾 食字史萊姆」除魔特訓（常錯題連對 2 次解除）。
* **智慧防撞與防矇對抽題演算法**：支援 **⚡ 智慧動態綜合闖關**、**✍️ 字形手寫專場（2 倍金幣牧草與雙倍孵蛋步數）**、**🔊 字音極速專場 (10 題)**，並內建「初見單次答對字音題 15% 鞏固回顧池」，避免四選一矇對一次就永不複習。

## 🧪 1. 如何在本地端、測試套件與 iPad 進行測試？

### A. 電腦本機開發、自動化測試與編譯
在專案根目錄開啟終端機執行：
```bash
# 1. 安裝套件（若尚未安裝）
npm install

# 2. 啟動開發伺服器
npm run dev

# 3. 執行 V2 自動化完整性測試套件（15 項題庫、奇獸、魔王與安全機制檢核）
npm test

# 4. 執行 TypeScript 檢查與正式版 PWA 打包
npm run build
```
啟動 `npm run dev` 後用瀏覽器打開 `http://localhost:5173` 即可開始遊玩。

### B. 讓同一個 Wi-Fi 下的 iPad 直接連線實機測試（推薦！）
若想立刻在 iPad 上用 Apple Pencil 測試手寫體驗：
```bash
npx vite --host --configLoader runner
```
終端機會顯示一組區域網路網址（例如 `http://192.168.1.xxx:5173`）。
只要 iPad 與電腦連上同一個 Wi-Fi，在 iPad 的 Safari 輸入該網址即可直接體驗！

### C. 本地測試完整 PWA 離線封裝效果
```bash
# 1. 打包正式版至 dist/ 資料夾
npm run build

# 2. 啟動正式版預覽伺服器
npm run preview
```

## 📄 2. 如何擴充題庫並自動補齊教育部辭典解釋？

### A. 用 PDF 考古題自動提取擴充題庫 (`scripts/extract-pdfs.mjs`)
1. 將 `.env.example` 複製為 `.env`，填入你的 `GEMINI_API_KEY`：
   ```env
   GEMINI_API_KEY=你的_Google_AI_Studio_金鑰
   ```
2. 將掃描版或文字版的語文競賽 PDF 考卷放入 [raw_pdfs/](./raw_pdfs/) 資料夾。
3. 執行轉檔指令：
   ```bash
   npm run extract-pdf
   ```
   腳本會自動提取字音與字形題、生成 3 個易混淆誘答注音、依 `${fullWord}_${type}_${targetIndex}` 自動去重並累加 `frequency`，寫入 [src/data/questions.json](./src/data/questions.json)。
   *(也可以在遊戲內的「右上角設定 ⚙️ ➔ 匯入自訂考古題庫 JSON」直接載入題庫檔)*

### B. 自動串接教育部辭典（萌典 Open Data）補齊詞義與字根 (`scripts/enrich-questions.mjs`)
新增題目後，可執行以下指令自動查詢教育部《重編國語辭典修訂本》開放資料，為新題目注入詞義解釋、單字部首釋義、典故出處、例句與一字多音家族對照：
```bash
npm run enrich-questions
```

## 🚀 3. 如何進行後續部署（讓 iPad 加入主畫面離線遊玩）？

由於 iOS / iPadOS 的 PWA 規範要求必須透過 **HTTPS** 才能啟用 Service Worker 離線快取與「加入主畫面」全螢幕模式，推薦以下兩種免費且最快速的部署方式：

### 方式一：使用 Vercel 部署（最推薦，免設定一鍵完成）
1. 將本專案推送至 GitHub 儲存庫後，前往 [Vercel](https://vercel.com/) 並使用 GitHub 登入，點擊 **"Add New Project"** 匯入該倉庫。
2. Vercel 會自動偵測為 **Vite** 框架：
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. 點擊 **Deploy**，約 1 分鐘即可獲得 `https://xxxx.vercel.app` 網址！（或直接在本機執行 `npx vercel` 快速部署）

### 方式二：使用 Cloudflare Pages 或 Netlify 拖曳部署
1. 先在本機執行 `npm run build`，專案根目錄會產生打包好的 [dist/](./dist/) 資料夾。
2. 登入 **Cloudflare Pages** 或 **Netlify Drop**，直接將 `dist` 資料夾拖曳上傳，即可立刻獲得免費的 `https://` 網址。

### 📱 在 iPad 上安裝為全螢幕 App 的步驟
1. 部署完成取得 `https://...` 網址後，使用 **iPad 的 Safari 瀏覽器** 打開該網址。
2. 點擊 Safari 右上角的 **「分享」圖示**（方框向上箭頭）。
3. 選擇 **「加入主畫面 (Add to Home Screen)」**。
4. 從 iPad 桌面點擊「字音字形牧場」圖示開啟，即可以無網址列的全螢幕 App 模式流暢遊玩，離線也能查詢教育部辭典釋義、練習字音字形與養成神獸！
